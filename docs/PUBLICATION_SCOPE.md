# 公开与维护范围

## 允许提交

- 经审阅的 Python 源码、测试、依赖声明、离线 CI 和文档。
- 24 条从头编写的合成招聘样例，以及测试动态生成的临时夹具。
- 空值环境变量模板；实际服务地址与凭据由本地环境提供。

## 保留在本地

真实岗位语料、Excel、原始论文及审稿材料、个人信息、API 凭据、私人服务地址、模型、权重、数据库、向量索引、预测正文、缓存和日志均不随源码发布。原实验目录和原始 Git 历史不自动同步到此仓库。

## 提交步骤

1. 在独立仓库创建分支，只选择完成去敏的具体源码文件。
2. 执行分类回归测试与公开边界测试；外部 API 只用模拟请求。
3. 将选定文件暂存后运行 `python tools/check_publication.py --staged`。此模式检查实际 Git index blobs，不用未暂存的干净文件代替。
4. 检查 `git diff --cached`、文件列表与 CI，通过 Pull Request 记录后续改动。

无参数的扫描严格检查整个工作目录，适用于无环境和缓存的干净导出。策略在 `publication-policy.json`；报告必须写到仓库外，默认使用父目录的 `audit/`。启发式扫描不是作者归属、许可或数据来源的证明，合成样例及每次迁移都需要人工核验。
